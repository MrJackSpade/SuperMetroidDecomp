# G-Mode gate parity (#406)

Affected version: Unknown (technique-parity audit)

## Cartridge behavior

The bounded original-CPU probe in `native-gmode-gate-probe.h` loads Kronic
Boost (`$8F:AE74`), runs its room population and two ordinary PLM frames, then
reproduces direct G-Mode's observable cartridge state:

- Wave Beam equipped;
- native PLM enable word `$1C23` cleared;
- all 40 native PLM slots occupied; and
- the left blue downward gate asleep at pre-instruction `$BB6B` and instruction
  list `$BC44`.

The probe drives the retail projectile producer, motion, collision, and PLM
handler with the original 65C816 routines. The committed CSV records that the
shot first crosses the gate center on frame 3. Calling native `EnablePLMs`
(`$84:83AD`) on frame 4 lets the collision-created PLM activate the switch on
frame 5. Calling it on frame 5 is too late. With no reactivation, the shot
passes but the switch remains inactive.

This provides both a successful timing and the adjacent one-frame failure. The
fixture is regenerated by applying `native-gmode-gate-entrypoint.patch` to the
pinned `upstream-sm` source, copying `native-gmode-gate-probe.h` beside
`sm_rtl.c`, rebuilding, and running:

```text
sm.exe --gmode-gate-probe "Super Metroid.smc" NEW.csv
```

## Port behavior

The port now represents the four cartridge subsystem-enable words explicitly:
enemy projectiles, PLMs, animated tiles, and palette FX. X-Ray setup suspends
all four. Reserve completion clears shared time freeze but deliberately leaves
those subsystem words suspended, producing direct G-Mode. A second X-Ray use
runs the common teardown boundary and restores them.

Door-transition cleanup removes the stranded X-Ray object without restoring the
four words, producing indirect G-Mode. Destination room setup may still run,
but disabled enemy-projectile creation discards the gate actor, matching the
cartridge omission rather than adding a gate-specific bypass.

The managed verifier uses the retail Kronic room, the production 40-slot PLM
pool, production Wave projectile motion/collision, and the committed native CSV.
It asserts the exact 4/5 reactivation boundary and separately asserts indirect
G-Mode's missing gate actor. No arbitrary WRAM corruption or visual-corruption
emulation is introduced.
